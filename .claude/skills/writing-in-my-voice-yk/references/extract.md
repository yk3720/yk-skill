# 特徴抽出

出力先は `c:/yk-memo/04.文章/特徴.md` のみ。稿の全文をここに貼らない。

## 読む対象

README が定める **媒体フォルダ** 内の `.md`。**除く:** 各 `README.md` · ルートの `特徴.md`。

件数が 8 を超えるときは README 一覧の新しい順 5 件 + 媒体が足りない分。
（8 は一度に読む上限。超えたら新しい順で間引く）

## フル再抽出（「特徴を書き出して」）

1. 対象稿を Read する
2. 稿に **実際に出てくる** 口調だけを `特徴.md` に書き直す。無いものは書かない
3. 構成は次に固定する（中身は稿から。媒体名は README のフォルダ名）

- **常時** — 口調 · 断定の弱め方 · 依頼 · 見出し記号 · 改行 · 現場用語
- **媒体別** — 稿がある媒体だけ節を書く。稿が無い媒体は「確定稿なし」と 1 行
- **起草時にやらないこと** — 確定稿で繰り返し直された一般化（AI がやりがちなずれ）

4. 最終更新日を稿の日付に合わせる

## 追記（保存と同時）

フル書き換えしない。新しい記号・型だけ、該当する媒体の節に足す。既存の行と矛盾したら稿を優先して直す。

## やらないこと

- 「ビジネスメールらしい」敬語を推定で足す
- チャット稿の型をメール節へコピーする
- 1 回きりの誤変換を特徴にする
- スキルの `patterns.md` を特徴の原本にする
