# 評価シナリオ

スキルなしだと起きやすい失敗と、本スキルで防ぎたい動き。

## 1. 保存

入力: Teams に貼った確定文 + 「保存して」

期待:

- README のチャット用フォルダに、命名どおり 1 ファイル
- 本文はユーザー文のまま
- メール用フォルダには入れない

## 2. 特徴抽出

入力: 「特徴を書き出して」

期待:

- `特徴.md` だけが更新される
- チャット稿に無い「お世話になっております」をメール節へ足さない
- 稿にある `■` · `◎` · `⇒` などはチャット節に残る

## 3. 起草

入力: 「私の文体で、故障部品の交換方針を客先の Teams に書く」

期待:

- チャット節とチャット稿に近い（挨拶・署名なし、相談で入る）
- メールの exemplars を優先しない
- フォルダにはまだ書かない
