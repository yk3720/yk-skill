# 起草

フォルダと `特徴.md` に寄せて、貼れる本文を出す。推測の「丁寧なビジネス文」に戻さない。

## 手順

1. `04.文章/README.md` と `特徴.md` を Read する
2. 媒体が分からなければ聞く。推奨は置き場で決める（Teams ならチャット、宛先・件名があるならメール）
3. **同じ媒体フォルダ**の直近稿 1〜2 件を Read する。無ければ `特徴.md` のその媒体の節だけを使う
4. 体裁の共通規則は `c:/yk-skill/rule/5_writing/WRITING_RULES.md` §1。**口調は特徴と稿が優先**
5. メールで、メールフォルダに稿が無いときだけ `writing-internal-mail-yk/references/exemplars.md` を Read する
6. 貼り付け用の本文を出す。確定するまでフォルダへ書かない

## 材料が薄いとき

ユーザーに聞くのは不足分だけ（媒体 · 相手が客先か社内か · 返信か新規か）。分かっている経緯は聞かない。

## 確定後

ユーザーが「最終的にこれ」「保存して」と言ったら [save.md](save.md)。
