# 保存

確定稿だけを `c:/yk-memo/04.文章/` に書く。媒体フォルダ・命名・置かないものは **README.md を Read** して従う。

## 手順

1. `04.文章/README.md` と `99.テンプレート/06.文章.md` を Read する
2. 媒体が分からなければ、README の分類を示して聞く。推奨は本文の置き場で決める（Teams に貼るならチャット、宛先・件名があるならメール）
3. 同一案件の追記（「追加です」）なら、同じ媒体フォルダの該当稿の末尾に足す。新規ならその媒体フォルダへテンプレ枠で作る
4. **区切り線より下はユーザー文をそのまま**にする。誤変換の指摘は会話のみ（本人が直すと言ったときだけ稿も直す）
5. ルート README の一覧行を足す（新規ファイルのとき）
6. 新しい見出し記号・依頼の言い回しがあれば、同じターンで `特徴.md` に追記する。手順は [extract.md](extract.md) の「追記」

## やらないこと

- AI が書いた下書きをフォルダへ入れる
- 客先本文を `yk-skill` 側へコピーする
- README の媒体名・命名をスキル内に書き直す
- 違う媒体フォルダへ入れる
