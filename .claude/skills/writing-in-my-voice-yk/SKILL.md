# Writing in My Voice（YK）

本人が確定した文章を溜め、そこから口調を抜き、同じ口調で新しい文を書く。

**Ask モードでは保存・特徴の書き込みはしない。** 貼り付け用の本文だけ出す。

## 依存

| 役割 | 正本 |
|------|------|
| フォルダ運用 · 命名 | `c:/yk-memo/04.文章/README.md` |
| 抽出した口調 | `c:/yk-memo/04.文章/特徴.md` |
| 新規稿の枠 | `c:/yk-memo/99.テンプレート/06.文章.md` |
| 体裁（句点改行 · ■） | `c:/yk-skill/rule/5_writing/WRITING_RULES.md` §1 |
| 社内・新規送付の型（該当稿が薄いとき） | `writing-internal-mail-yk/references/exemplars.md` |

口調の中身は `特徴.md` と各稿。ここへコピーしない。

## モード

依頼から **1 つ**選ぶ。迷ったら推奨は表の上から。

| モード | 発火の目安 | 手順 |
|--------|------------|------|
| **保存** | 「保存して」「追加です」+ 本文 | [save.md](references/save.md) |
| **特徴抽出** | 「特徴を書き出して」「特徴を更新」 | [extract.md](references/extract.md) |
| **起草** | 「私の文体で」「文章を作って」「客先メール」「Teams」 | [draft.md](references/draft.md) |

保存のあと、新しい記号・見出しが出ていれば **同じターンで特徴を追記**する（フル再抽出は「特徴を書き出して」のときだけ）。

## 境界

| 使う | 使わない |
|------|----------|
| 客先・社内の短い実務文の保存 · 分析 · ゼロからの起草 | 既存文の洗練ループ（`refining-copy-yk`） |
| 確定稿だけをフォルダへ | AI 下書きのフォルダ保存 |
| 貼り付け用の本文 | 長い提案書（`writing-proposals`）· 図解 HTML |
