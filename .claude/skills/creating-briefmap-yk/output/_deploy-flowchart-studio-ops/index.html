  1. 有償クラウド（月 約 $50 · 構成 B）の利用可否
  2. 社内設計データ（社内番号 · 装置名 · PLCコメント等）の外部クラウド保存可否
  3. 本番化時のサービスアカウント名義（個人 → 会社）の取得可否

  • 結論：本番運用は構成 B（Vercel Pro + Supabase Pro + FastAPI/Railway · 月 $50）を推奨
  • 現状：構成 A 相当 · 無料枠 · PoC 公開中（FastAPI 未デプロイ）

調査結果 · 現状（PoC） 事実

  • Web 版の基本機能は実装済み（表編集 · 図プレビュー · 保存 · PNG/SVG · ログイン）
  • Vercel + Supabase 無料枠で公開中（月 $0）
  • FastAPI は未デプロイ — Excel 変換は作者 PC の exe → import.json 取込
  • 現フェーズは「調査 · 検証」。方針確定後に開発を進める

推奨：構成 B 提案

構成 B — Vercel Pro + Supabase Pro + FastAPI（Railway）。正式運用ならログイン認証あり。

  • ブラウザから装置 xlsx 変換まで完結（FastAPI 組み込み）
  • 正式運用にはログイン · ユーザー管理が必要（共用 admin は検証用のみ）
  • Railway は月 $5 程度 — 追加コストは小さい
  • PLC コメントとフローの対応づけにはクラウド保存 · 認証付き Web が前提
  • 推奨構成は完全無料では実現できない
  • PoC（A）から本番（B）への移行が年度テーマ（1装置分 · 実用化）に自然

運用構成（4択） 事実

構成 内容 月額 位置づけ
A 無料枠 · FastAPI なし $0 現状 · 検証用 PoC
B 推奨 本番 · 認証あり · FastAPI あり $50〜 本番運用
C 本番 · 認証なし · FastAPI あり $25〜35〜 低コスト Web
D デスクトップ（Python+Excel） $0 選定時想定

B/C の差（ログイン要否）は月 $15〜25 程度 · 面談で相談可。

Web版を選んだ理由（Excel+オートシェイプとの比較） 事実

アカウント：現状は個人名義。本番（B/C）では会社名義への移行を推奨。

保存データの扱い 事実

  • 含む：社内番号 · 装置名 · フロー表 · PLC コメント（リンク予定）
  • 含まない想定：客先名 · 契約情報等
  • 社内番号 · 装置名だけでは客先特定不可
  • 装置名の付け方で客先が推測される場合 → 運用ルールとして別途相談

リスク（無料枠のまま本番にしない理由） 事実

  • Supabase Free：1週間非アクセスで DB 一時停止 · 自動バックアップなし
  • Vercel Hobby：非商用 · 個人向け — 有給業務の継続利用は規約上グレー
  • 個人アカウント：退職 · 請求 · 継続性のリスク
