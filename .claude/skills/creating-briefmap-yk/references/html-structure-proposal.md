# BriefMap — HTML 構造（preset: proposal-only）

`references/base.html` の CONTENT 領域に挿入。

## ヘッダー

- バッジ: `BriefMap · 【提案】` または `【依頼】`
- `h1` · **結論1行（お願い）** を `header` 直下にも重ねて表示可
- メタ（読者 · 正本 · 日付）

## セクション id

| 順 | id | 内容 | 種別 | 必須 |
|----|-----|------|------|------|
| 0 | notice | 判断・提案依頼である旨 | — | yes |
| 1 | ask | お願い（結論 · N 点） | 提案 | yes |
| 2 | issue | 現状の課題 | 事実 | 正本にあれば |
| 3 | options | 選択肢比較 | 事実 | yes |
| 4 | recommend | 推奨と理由 | 提案 | yes |
| 5 | risks | リスクと対策 | 事実+解釈 | 正本にあれば |
| 6 | terms | 用語 | — | 任意 |
| 7 | refs | 正本 · URL | — | yes |

**含めない:** 長い調査詳細（正本別資料へリンク）。必要最小の事実のみ `issue` に。

## notice 帯

> 本資料は **方針・予算等のご判断** をお願いする提案です。詳細調査は正本テキストを参照してください。
