# BriefMap — HTML 構造（preset: supervisor · 既定）

**用途:** 上司が「何の話か」を初めて読むとき。**状況 · 理由（Web/有料）· お願い。** 技術詳細は正本 + 面談。

`references/base.html` の CONTENT 領域に挿入。

## 禁止（supervisor では載せない）

- サービス名一覧（Vercel / Supabase 等）
- A/B/C/D の詳細表 · 技術比較表
- 事実/解釈/提案ラベル · BriefMap 等のメタバッジ
- 用語集 · 参考文献の長い一覧
- 正本にないたとえ · 一般論

## ヘッダー

- `h1`: **業務語**で何のツールか（例: フローチャート作成ツール）
- 1段落: 上司が知っている前提（「検討している」）から、**何ができる試作か**を平易に
