# BriefMap — 文言洗練（supervisor）

上司向けブリーフの **本文・リスト項目** を短く整えるときの SSOT。  
初回生成後のブラッシュアップ（Phase 2）およびユーザーから「洗練」「短く」等の指摘があったときに Read。

---

## 1. 洗練の定義（ユーザー基準）

**必要最低限の文字数で意図を伝える。**

- 多すぎる → 上司の読む負荷が上がり、要点が埋もれる
- 少なすぎる → 判断材料が欠け、誤解や追問が増える

目安: 各リスト項目は **1 文** を基本。短縮しても **正本テキスト（01 等）の事実・叙述フローは欠落させない**。

---

## 2. 作業順（レビュー前必須）

文言を直す・レビューする **前に** 次をすべて Read する。

1. 対象 HTML の **全文**（ヘッダー〜フッター）
2. 正本テキスト（例: `01_調査報告_概要.txt`）
3. 同フォルダの設計メモ・議論ログ（あれば）

### 文体整合チェック

| 観点 | 確認内容 |
|------|----------|
| 語尾 | 「している／する」体で揃える。**一部だけ「である」** にしない |
| ラベル | 番号リストの各項目 — **全項目に短ラベル** か **全項目ラベルなし** のどちらかに統一（混在禁止） |
| 重複 | ヘッダーと①の説明 · ①と④の「調査」 · 本文と直後の URL 誘導 · ⑤と「大枠の二択」カード |
| トーン | 断定（「必要になる」）より、正本に合わせ **「見込み」「判断が必要」** 等の余地を残す |
| 区切り | 文内は半角中黒 `·`（プロジェクト慣習に合わせる） |
| 強調 | `<strong>` は項目あたり **1〜2 か所** — 判断語・コスト関連に限定 |

---

## 3. サブエージェントレビュー

**「文章を洗練」** とユーザーが明示したときは、レビュー→修正ループ全体を **`refining-copy-yk`** に委譲する。本ファイル §2〜§5 を併用 Read すること。

次のいずれかのときのみ、本節の手順で **generalPurpose** サブエージェントにコピーレビューを委譲する（修正ループなし · ユーザー明示時は必須）。

- ユーザーが「サブエージェントでレビュー」と依頼した
- 「いまの状況」等、**5 項目以上の叙述ブロック** を大幅に書き換える
- 親エージェントが文体不整合を複数検出した

### サブエージェントへの渡し物

- 対象セクションの現行文
- 周辺セクション（重複チェック用）
- 正本の該当箇所要約
- 設計メモの叙述フロー（意図的に残す語句）
- 本ファイル §2 の整合チェック結果

### サブエージェントに求める出力

1. 文体整合性（重大度付き）
2. 改訂案 **2〜3 パターン**（推奨案を 1 つ明示）
3. 項目ごとの字数比較（現行 → 改訂）
4. 正本との矛盾・上司の誤解リスク
5. `<strong>` の付け方提案

採用案を HTML に反映したら、プロジェクト側の **設計メモ・議論ログ** に日付 · 理由を追記する。

## 4. 「いまの状況」リスト（supervisor · 5 項目）

`preamble` と `status` は **1 セクション「いまの状況」に統合** する（内容がすべて現状報告のため）。

| 順 | ラベル（`<strong>`） | 載せること |
|----|----------------------|------------|
| 1 | 経緯： | 調査 · **自分がベストだと考える**判断 · 叩き台作成 |
| 2 | 進捗： | 試作の動作 · **個人検証用の無料枠**で公開 |
| 3 | 位置づけ： | 本番前提は未確定 · 方針確定後に開発 |
| 4 | 本番運用： | 課内本番には **有償クラウド**（後述 N 種）が必要になる **見込み** |
| 5 | 有償が難しい場合： | **無償でできる範囲**に絞り再検討（語尾は他セクションと揃える） |

**載せない:** 月額 · 構成記号 · 「下記 URL」（URL はリスト直後の別行）

**短縮の典型:**

- ヘッダーで Web ツール説明済み → ①は「Web 版」より「形」等、重複しない語を選ぶ
- ④から「調査の結果」を削る（①で済）
- 口語ラベル（「有償 NG 時」）は避け「有償が難しい場合：」

### strong の付け方（例）

```html
<strong>進捗：</strong>試作版は動作中。<strong>個人検証用の無料枠</strong>で公開している。
```

- ラベル行はすべて `<strong>ラベル：</strong>`
- 本文は **ベスト判断 · 無料枠 · 有償 · 無償範囲** など判断に効く語のみ

## 5. よくある不整合（レビュー観点）

| 症状 | 対処 |
|------|------|
| 5 項目だけ「である」 | 「する／している」に統一 |
| 2・3 だけラベル付き | 1〜5 すべてに短ラベル |
| ①④で「調査」二重 | ④は結論（本番要件）のみ |
| 「下記 URL で触れる」 | 削除（URL 行を直下に置く） |
| 「必要になる」だけ | 「見込み」を添える（正本トーン） |
| ⑤と choice カードで語尾不一致 | 同じ述語（例: 「再検討する」）に揃える |
