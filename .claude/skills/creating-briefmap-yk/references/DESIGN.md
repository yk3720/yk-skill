# BriefMap — 設計メモ（SSOT）

**形式 id:** `briefmap`  
**スキル:** `creating-briefmap-yk`  
**最終更新:** 2026-07-05（supervisor 既定 · ローカル納品）

---

## 1. 目的

| 項目 | 内容 |
|------|------|
| **図解の役割** | **状況報告 + 何をしてほしいか** のみ |
| **詳細** | 正本テキスト（01 等）+ **面談** — 図解に載せない |
| **読者** | 上司（ツール概要程度しか知らない想定） |
| **納品（既定）** | **ローカル HTML**（指定パスへ保存） |
| **surge** | ユーザー明示時のみ |

---

## 2. プリセット

| preset | 用途 |
|--------|------|
| `supervisor`（既定） | 状況 · お願い · 大枠の二択 |
| `hybrid` | 比較表 · サービス構成（明示依頼時） |
| `report-only` | 共有のみ · 判断依頼なし |

---

## 3. 上司視点の原則（supervisor）

1. 冒頭で **何のツールか** を業務語で書く
2. **構成 B / PoC / SaaS 名** を図解本文に出さない（円換算の金額は可）
3. メタラベル（BriefMap · 事実/解釈）を付けない
4. 「詳細は 01 · 面談」で誘導

---

## 4. ファイル

| 項目 | 規約 |
|------|------|
| 作業用 | `output/{slug}.html` |
| 納品 | ユーザー指定（例: `docs/.../図解_補足.html`） |
| surge 正本 | `c:/yk-tool/publish/briefmap-{slug}.html`（公開時のみ） |
